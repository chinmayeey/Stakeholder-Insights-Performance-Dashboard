# 📊 Stakeholder Insights and Performance Dashboard

An interactive business intelligence dashboard designed to analyze stakeholder performance, insurer contributions, premium trends, profitability indicators, and Assets Under Management (AUM). The project helps transform financial and stakeholder data into meaningful insights for better business decision-making.

## 📌 Project Overview

The **Stakeholder Insights and Performance Dashboard** provides a comprehensive overview of key business metrics related to stakeholders, insurers, and policy performance.

The dashboard focuses on identifying performance trends, understanding stakeholder contributions, analyzing insurer value creation, and exploring asset distribution across different categories.

## 🎯 Project Objectives

- Analyze the value created by different insurers.
- Monitor premium trends over time.
- Understand stakeholder shareholding patterns.
- Explore cost ratio and profitability indicators.
- Compare performance across cities and policy tenures.
- Analyze Assets Under Management across stakeholders.
- Enable data-driven business decisions through interactive visualizations.

## 📂 Dataset Description

The project uses an Excel dataset containing **9,999 financial records and 18 columns**.

Key attributes include:

| Column | Description |
|---|---|
| Stakeholder | Stakeholder category |
| Insurer | Insurer category |
| Value Created | Value generated |
| Shareholding Pattern | Ownership category |
| City | Geographic location |
| Brokers | Broker information |
| Premium | Premium category |
| Date | Record date |
| Profitability | Profitability indicator |
| Cost Ratio | Cost ratio category |
| Assets Under Management | Equity or Debt |
| Educational Qualifications | Education category |
| Policy Tenure | Policy duration |
| Gender | Stakeholder gender |
| Age | Stakeholder age |

## 📈 Dashboard Features

### 1. Key Performance Indicators (KPIs)

- Total Premium Collected
- Average Age of Stakeholders
- Total Value Created for Equity Assets Under Management
- Highest Value Created by a Single Insurer

### 2. Data Visualizations

- **Insurer Performance Analysis:** Comparison of value created by different insurers.
- **Premium Trend Analysis:** Visualization of premium trends over time.
- **Shareholding Distribution:** Analysis of stakeholder ownership patterns.
- **Cost Ratio vs. Profitability:** Exploration of financial performance indicators.
- **City-wise Profitability:** Comparison of profitability across different cities.
- **Policy Tenure Analysis:** Performance analysis across policy duration categories.
- **Assets Under Management:** Distribution of assets across stakeholder categories.

### 3. Interactive Filters

The dashboard includes filtering options to support detailed analysis:

- City
- Stakeholder
- Policy Tenure
- Date Range
- Gender

### 4. Interactive Dashboard Experience

- Dynamic KPI updates based on filter selections.
- Interactive charts for deeper analysis.
- Tooltips displaying additional information.
- Cross-filtering between visualizations.

### 5. Export Functionality

- PDF export functionality.
- Export of dashboard visuals and KPIs.
- Company branding watermark on exported reports.

### 6. User Access

Role-based access to support different data visibility levels for stakeholders.
